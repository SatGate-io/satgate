# LangChain Integration — Coming Soon

> 🚧 **This integration is under development.**

We're building a LangChain integration that will let you add SatGate budget enforcement to any LangChain agent chain. Until then, you can use SatGate as an HTTP proxy in front of your LLM provider — no SDK required.

See the [MCP Gateway Guide](mcp-gateway.md) for how SatGate works with AI agent tool calls today.

**Want to contribute?** [Open an issue](https://github.com/SatGate-io/satgate/issues) to discuss the integration design.
