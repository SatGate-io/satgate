# SDKs & Client Libraries

> 🚧 **Official SDKs are under development.**

SatGate exposes a standard HTTP/REST API that works with any language. Official SDKs will provide idiomatic wrappers for common operations like token creation, budget checking, and macaroon delegation.

**Planned SDKs:**
- Python — Coming Soon
- Node.js — Coming Soon
- Go — Coming Soon

**Agent SDKs (middleware for AI frameworks):**
- Python Agent SDK — Coming Soon
- Node.js Agent SDK — Coming Soon

In the meantime, use the [API Overview](../api/overview.md) to integrate directly.

**Want to help build an SDK?** [Open an issue](https://github.com/SatGate-io/satgate/issues) or check the repo for contribution guidelines.
